# System-Zarzadzania-Hotelem

Projekt realizowany jest w ramach przedmiotu Programowanie Obiektowe (Temat 5: System Zarządzania Hotelem). Aplikacja zaimplementowana jest w języku C++17, ściśle realizuje zasady projektowania obiektowego.

## Wymagania i kompilacja

Projekt wymaga kompilatora obsługującego standard C++17.

Kompilacja za pomocą `g++`:

`g++ -std=c++17 main.cpp faktura.cpp gosc.cpp osoba.cpp pokoj.cpp recepcjonista.cpp rezerwacja.cpp systemHotelu.cpp uslugaDodatkowa.cpp -o hotel_system`

Uruchomienie programu:

- Linux / macOS:
`./hotel_system`

- Windows:
`hotel_system.exe`
